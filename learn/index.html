초급 과정

악보를 몰라도 피아노 위치와 리듬을 익히는 단계

1. 건반 이름 익히기

C3-B5 위치, 흰 건반/검은 건반 구분

2. 한 음씩 따라 치기

초록색 건반을 보고 단일 음 인식 연습

3. Falling Notes 입문

맨 밑 막대와 건반 위치를 맞춰 치기

4. 4마디 멜로디

E-A-B-G-C 순서의 짧은 멜로디 완주

중급

중급 과정

양손 패턴과 코드 진행을 함께 익히는 단계

1. 왼손 베이스 루프

C3-G3-A3-F3 반복 패턴

2. 오른손 멜로디 연결

G4-C5 도약과 손 위치 이동

3. K-POP 코드 진행

C-G-Am-F 진행을 피아노 롤로 연습

4. 양손 동시 입력

같은 타이밍의 여러 NoteEvent 처리

3. 음원 변환 곡
